# roBa-key-case
kuma_key氏(@km080mhk)により設計されたroBaのLPキーケースを改修。  
本家：https://github.com/kumamuk-git/roBa     

トラックボールケースが10mm左側に来るようにオフセットし、ケース本体もフィットするように修正。  
ケース作成はけぺお氏(@kepeoo)のブログ参考。  
ブログ記事：https://kepeo.hatenablog.com/entry/2025/05/17/005608

v2ではMCUが見える設計に変更。
